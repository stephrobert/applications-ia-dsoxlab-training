# portail-achats

Purchasing portal built with an AI assistant by a buyer of the purchasing
department. Portail achats construit avec un assistant d'IA par une acheteuse
du service achats.

- `application.yaml`: the application contract, a REQUEST to the platform.
  La fiche applicative, une DEMANDE faite à la plateforme.
- `schema/`: a schema the coding agent wrote for itself.
  Un schéma que l'agent de code s'est écrit pour lui-même.
