# portail-achats: order module

Purchasing portal of a fictional company, built with a coding agent.

- `.claude/settings.json`: the permission rules of the team.
- `managed/`: stands for the managed settings of the machine.
- `docs/policy.md`: the permission policy, project level and managed level.
- `agent/`: the simulated agent of the lab (not Claude Code) and its scenario.
- `src/`: the code. `secrets/`: credentials the agent must never read.
