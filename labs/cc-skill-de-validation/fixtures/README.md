# portail-achats: order module

Purchasing portal of a fictional company, built with a coding agent.

- `src/`, `tests/`: the code and its unit tests.
- `tools/validation/`: the three validation scripts the CI runs.
- `docs/validation.md`: the validation procedure, and what the team decided for the skill.
- `.claude/skills/valider/`: the first version of the /valider skill.
- `bench/`: the skill bench of the lab (not Claude Code).
