# reassort-stock

**Requested by:** a warehouse team leader. **Requested class:** C2.

## Request (EN)

"We are only three in the warehouse team. The tool computes how much to
reorder for each item, then writes the new reorder thresholds directly into
the ERP. It only handles item references and stock levels, nobody's name. If
it stopped, we would set the thresholds by hand again: it is useful, not
vital. For three people, C2 is plenty."

## Demande (FR)

« On n'est que trois dans l'équipe de l'entrepôt. L'outil calcule combien
réapprovisionner pour chaque article, puis écrit directement les nouveaux
seuils de réapprovisionnement dans l'ERP. Il ne manipule que des références
d'articles et des niveaux de stock, aucun nom de personne. S'il s'arrêtait, on
reprendrait les seuils à la main : c'est utile, pas vital. Pour trois
personnes, C2 suffit largement. »
