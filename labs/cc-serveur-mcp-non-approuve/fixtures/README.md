# portail-achats: order module

Purchasing portal of a fictional company, built with a coding agent.

- `.mcp.json`: the MCP servers of the project, shared with the team.
- `.claude/settings.json`: the permissions of the project, shared with the team.
- `docs/mcp-servers.md`: the MCP servers the security review approved.
- `tools/`: stand-ins for the MCP servers (simulated, never started).
- `bench/`: the MCP bench of the lab (not Claude Code).
