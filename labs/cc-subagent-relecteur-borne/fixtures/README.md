# portail-achats: order module

Purchasing portal of a fictional company, built with a coding agent.

- `.claude/agents/relecteur.md`: the subagent that reviews a branch before a merge.
- `.claude/agents/correcteur.md`: the subagent that applies the fixes a human asked for.
- `docs/review-incident.md`: what the reviewer did during the last review.
- `src/orders.py`: the code under review.
- `bench/`: the subagent bench of the lab (not Claude Code).
